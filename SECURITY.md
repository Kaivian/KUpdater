# Security Policy

## Reporting a Vulnerability

We take the security of **KUpdater** seriously. If you discover a security vulnerability or exploit in KUpdater or any of its modules, please report it responsibly.

### Responsible Disclosure

* **Do not** report security vulnerabilities through public GitHub issues or public chat channels.
* Please submit security advisories privately using GitHub's **Private Vulnerability Reporting** feature under the **Security** tab of the repository.
* Provide detailed steps to reproduce the vulnerability, including affected server versions, KUpdater version, and configuration details.

### Security Expectations

* **Supported Versions**: Only the latest release on the `main` branch receives security updates.
* **Exploit Prevention**: Features designed for KUpdater must incorporate checks to prevent duplication exploits, permission bypasses, or server crash vectors.
