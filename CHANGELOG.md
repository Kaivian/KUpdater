# Changelog

All notable changes to KUpdater will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Initial project structure and Gradle wrapper configuration (`Paper API 26.2`, `Java 25`).
- Core modular API foundation (`KModule` interface, `ModuleCategory` enum).
- Central module management system (`ModuleManager`).
- Core configuration management system (`ConfigManager`).
- GitHub CI/CD workflows (`build.yml`, `release.yml`).
- GitHub issue templates (`bug_report.yml`, `feature_request.yml`, `compatibility_issue.yml`).
- GitHub pull request template (`pull_request_template.md`).
- Project documentation and developer guidelines (`docs/`).

### Planned

- Implementation of gameplay enhancement modules (Tools, Combat, Farming, Mining, Economy, Exploration, QoL).
- Advanced module configuration system and hot-reloading capabilities.
- Per-module documentation and permissions structure.
